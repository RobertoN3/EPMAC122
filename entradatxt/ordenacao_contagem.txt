7. Titulo: Ordenação por contagem (frequências)

## Ideia geral

Todos os métodos de [[ordenacao|ordenação]] vistos até aqui comparam pares
de elementos, e por isso nenhum deles consegue ser mais rápido que
n log n no pior caso. A ordenação por contagem (counting sort, chamada no
material da disciplina de ordenação por frequência) não compara elementos:
ela CONTA quantas vezes cada valor aparece e usa essas contagens para
calcular onde cada elemento deve ficar.

O preço é uma hipótese sobre os dados: os valores precisam estar numa faixa
pequena e conhecida, o "universo" {0, 1, ..., U-1}. Notas de 0 a 10,
idades, letras de 'a' a 'z' e dígitos de 0 a 9 são bons exemplos.

## A ideia em três passos

A contagem usa um vetor freq, com uma posição para cada valor possível,
generalizando o "vetor de bits" usado para
[[conjuntos|representar conjuntos]]: em vez de 0 ou 1 (está ou não está),
freq[x] guarda QUANTAS vezes x aparece.

1) Contar: percorrer o vetor e fazer freq[v[i]]++ para cada elemento.
2) Acumular: transformar as contagens em posições. Depois de acumular,
   freq[x] é o número de elementos MENORES que x, ou seja, a posição onde
   deve ficar a primeira ocorrência de x.
3) Distribuir: percorrer o vetor de novo, da esquerda para a direita, e
   copiar cada elemento v[i] para aux[freq[v[i]]], incrementando
   freq[v[i]] para que a próxima ocorrência do mesmo valor vá para a
   posição seguinte. Por fim, copiar aux de volta para v.

O material da disciplina usa um truque de índices: a frequência de x é
anotada em freq[x+1]. Assim, depois da soma acumulada, freq[x] já é a soma
das frequências dos valores menores que x, sem precisar de outro ajuste.

## Exemplo

v = (3, 1, 4, 1, 5, 2, 3, 0), U = 6.

```
  valor x:                    0  1  2  3  4  5
  1) frequências:             1  2  1  2  1  1
  2) posição inicial de x:    0  1  3  4  6  7    (quantos são menores)
  3) distribuindo v da esquerda para a direita:
       3 -> pos 4    1 -> pos 1    4 -> pos 6    1 -> pos 2
       5 -> pos 7    2 -> pos 3    3 -> pos 5    0 -> pos 0
  resultado:  (0, 1, 1, 2, 3, 3, 4, 5)
```

## Análise

- Tempo: contar é O(n), acumular é O(U), distribuir e copiar de volta é
  O(n). Total: O(n + U). Se U não é muito maior que n, a ordenação é
  LINEAR, mais rápida que qualquer método por comparação.
- Memória: o vetor de frequências (U + 1 posições) e o vetor auxiliar (n
  posições): O(n + U).
- Estabilidade: os elementos são distribuídos na ordem em que aparecem no
  vetor original, e cada ocorrência de um valor vai para a posição seguinte
  à anterior. Elementos iguais mantêm a ordem relativa: o método é
  [[estabilidade|estável]].

Quando não usar: se U é enorme em relação a n (ordenar 100 números
quaisquer de 32 bits exigiria um vetor de 4 bilhões de contadores), ou se
as chaves não são inteiros pequenos. Nesse caso, ou se usa um método por
comparação, ou o [[radixsort|Radix Sort]], que aplica a contagem dígito a
dígito e por isso depende da estabilidade dela.

No material da disciplina, o método é apresentado como exemplo do
paradigma guloso: cada elemento é colocado diretamente na sua posição
definitiva, sem voltar atrás.

## Ordenando nomes com um vetor de ordem

Ao ordenar [[registros]] ou cadeias de caracteres, mover os dados custa
caro: trocar dois nomes com strcpy copia todos os caracteres. Uma saída,
também estudada na disciplina, é não mover os dados e ordenar um VETOR DE
ORDEM: um vetor de índices ordem[0..n-1], inicialmente (0, 1, ..., n-1).
O algoritmo de ordenação compara nome[ordem[i]] com nome[ordem[j]], mas
troca apenas os índices ordem[i] e ordem[j]. No fim, a lista ordenada é
nome[ordem[0]], nome[ordem[1]], ..., e o vetor original continua intacto.

Vantagens:
- cada troca move um inteiro, e não uma cadeia inteira;
- várias ordens diferentes do mesmo vetor podem coexistir (por nome, por
  idade...), cada uma com o seu vetor de ordem;
- é a mesma ideia de ordenar ponteiros em vez de registros.

Com a [[bubblesort|bolha]], o número de comparações continua O(n²), e cada
comparação de cadeias custa até o comprimento L delas: O(n² · L). Já a
ordenação por frequência, aplicada letra a letra (do último caractere para
o primeiro, sempre de forma estável), ordena nomes em tempo proporcional a
n · L, sem nenhuma comparação de cadeias: é o Radix Sort para cadeias.

## Histórico

Harold H. Seward descreveu a ordenação por contagem em 1954, na sua
dissertação de mestrado no MIT, junto com a versão do Radix Sort que usa
contagem em cada dígito; a atribuição é de Knuth. A ideia de distribuir
itens em compartimentos de acordo com o valor é mais antiga e vem das
máquinas classificadoras de cartões perfurados.

O programa ordena o vetor do exemplo por contagem (com o truque do índice

não é alterado.

#include <stdio.h>
#include <string.h>
#define U 6           /* universo: valores de 0 a U-1 */
#define N 8

/* ordena v[0..n-1], com valores em 0..U-1, por contagem (estável) */
void ordena_contagem(int v[], int n) {
  int freq[U + 1] = {0}, aux[N], i;
  for (i = 0; i < n; i++) freq[v[i] + 1]++;       /* 1) contar (índice + 1) */
  for (i = 1; i <= U; i++) freq[i] += freq[i - 1]; /* 2) acumular */
  for (i = 0; i < n; i++) aux[freq[v[i]]++] = v[i]; // 3) distribuir
  for (i = 0; i < n; i++) v[i] = aux[i];
}

/* bolha sobre um vetor de ordem: troca índices, não os nomes */
void bolha_ordem(const char *nome[], int ordem[], int n) {
  int fim, i, t;
  for (fim = n - 1; fim > 0; fim--)
    for (i = 0; i < fim; i++)
      if (strcmp(nome[ordem[i]], nome[ordem[i + 1]]) > 0) {
        t = ordem[i]; ordem[i] = ordem[i + 1]; ordem[i + 1] = t;
      }
}

int main(void) {
  int v[N] = {3, 1, 4, 1, 5, 2, 3, 0}, i;
  const char *nome[] = {"Pedro", "Ana", "Lucas", "Beatriz", "Joana"};
  int ordem[5] = {0, 1, 2, 3, 4};

  ordena_contagem(v, N);
  printf("contagem:");
  for (i = 0; i < N; i++) printf(" %d", v[i]);
  printf("\n\n");

  bolha_ordem(nome, ordem, 5);
  printf("vetor de ordem:");
  for (i = 0; i < 5; i++) printf(" %d", ordem[i]);
  printf("\nnomes em ordem:");
  for (i = 0; i < 5; i++) printf(" %s", nome[ordem[i]]);
  printf("\nvetor original:");
  for (i = 0; i < 5; i++) printf(" %s", nome[i]);
  printf("\n");
  return 0;
}
