6. Problema: Dada uma expressão aritmética na notação usual (infixa), com parênteses e operadores de precedências diferentes, convertê-la para a notação posfixa, calcular o seu valor e representá-la por uma árvore binária
7. Titulo: Expressões aritméticas: infixa, posfixa e árvore de expressão

## Ideia geral

Escrevemos expressões aritméticas na notação INFIXA, com o operador entre
os operandos: 2 + 3 * 4. Ela é natural para nós, mas exige regras
extras para não ser ambígua:
- precedência: * e / são feitos antes de + e -, então 2 + 3 * 4 vale 14,
  e não 20;
- associatividade: operadores de mesma precedência são feitos da esquerda
  para a direita, então 9 - 4 - 3 vale 2, e não 8;
- parênteses, para mudar a ordem: (2 + 3) * 4 vale 20.

Há outras duas notações que dispensam tudo isso:
- PREFIXA (ou polonesa): o operador vem antes dos operandos: + 2 * 3 4;
- POSFIXA (ou polonesa reversa): o operador vem depois: 2 3 4 * +.

Na posfixa não há parênteses nem regras de precedência: a ordem dos
símbolos já diz a ordem das contas. É por isso que computadores convertem
as expressões para a posfixa (ou para uma árvore) antes de calculá-las.
Esta página mostra os três algoritmos que fazem isso, todos baseados em
[[pilhas]].

## Avaliar uma expressão posfixa

Percorre-se a expressão da esquerda para a direita com uma pilha de
valores:
- ao ler um operando, empilha-o;
- ao ler um operador, desempilha dois valores (primeiro o da DIREITA,
  depois o da ESQUERDA), aplica o operador e empilha o resultado;
- no fim, o valor da expressão é o único elemento da pilha.

```
  5 3 + 2 * 8 4 / -
  lê 5, 3      pilha: 5 3
  lê +         pilha: 8          (5 + 3)
  lê 2, *      pilha: 16         (8 * 2)
  lê 8, 4, /   pilha: 16 2       (8 / 4)
  lê -         pilha: 14         (16 - 2)
```

A ordem dos dois desempilhamentos importa nas operações que não são
comutativas: em "8 4 /", o 4 sai primeiro, mas a conta é 8 / 4. Cada
símbolo é tratado uma vez: tempo O(n).

## Converter de infixa para posfixa

O algoritmo da estação de manobras (shunting-yard), de Dijkstra, usa uma
pilha de OPERADORES. Os operandos vão direto para a saída, na mesma ordem;
os operadores esperam na pilha até que a sua vez chegue:
- operando: vai para a saída;
- "(": empilha;
- ")": desempilha para a saída até encontrar o "(", que é descartado;
- operador op: enquanto o topo da pilha for um operador de precedência
  MAIOR OU IGUAL à de op, desempilha-o para a saída; depois empilha op
  ("igual" faz os operadores de mesma precedência saírem da esquerda para
  a direita);
- no fim, desempilha tudo para a saída.

Exemplo com (5 + 3) * 2 - 8 / 4:

```
  lido  saída              pilha
  (                        (
  5     5                  (
  +     5                  ( +
  3     5 3                ( +
  )     5 3 +                       (desempilha até o "(")
  *     5 3 +              *
  2     5 3 + 2            *
  -     5 3 + 2 *          -        (* tem precedência maior: sai antes)
  8     5 3 + 2 * 8        -
  /     5 3 + 2 * 8        - /      (/ tem precedência maior que -: fica)
  4     5 3 + 2 * 8 4      - /
  fim   5 3 + 2 * 8 4 / -
```

O nome vem da imagem de um pátio ferroviário: os vagões (operandos) seguem
em frente, e as locomotivas (operadores) esperam num desvio até poderem
entrar no trem. Também é O(n).

## A árvore de expressão

Uma expressão também pode ser representada por uma
[[arvores|árvore binária]]: as folhas são os operandos e cada nó interno
é um operador, cujas subárvores esquerda e direita são os seus dois
operandos. A expressão (5 + 3) * 2 - 8 / 4 fica:

```
                -
              /   \
             *     /
            / \   / \
           +   2 8   4
          / \
         5   3
```

O operador da raiz é o último a ser calculado. Os parênteses
desaparecem: a própria forma da árvore diz o que é calculado antes.

Os três percursos [[recursao|recursivos]] dão as três notações:
- pré-ordem (raiz, esquerda, direita): - * + 5 3 2 / 8 4, a prefixa;
- pós-ordem (esquerda, direita, raiz): 5 3 + 2 * 8 4 / -, a posfixa;
- in-ordem (esquerda, raiz, direita): 5 + 3 * 2 - 8 / 4, a infixa, mas
  SEM os parênteses. Lida da esquerda para a direita com as regras de
  precedência, ela daria 5 + 6 - 2 = 9, e não 14. Para recuperar a
  expressão certa, a in-ordem precisa escrever "(" antes de visitar a
  subárvore esquerda de um operador e ")" depois da direita:
  (((5 + 3) * 2) - (8 / 4)).

Calcular o valor pela árvore é um percurso em pós-ordem: o valor de um nó
interno é o seu operador aplicado aos valores das duas subárvores, que
precisam ser calculados antes. Na árvore acima, a altura (medida em
arestas, com a raiz na altura 0) é 3, e há 5 folhas e 4 operadores. Numa
árvore de expressão com operadores binários, o número de folhas é sempre o
número de operadores mais 1.

## Montar a árvore a partir da posfixa

O algoritmo é o mesmo da avaliação, trocando valores por
[[ponteiros]] para nós (cada nó é um [[registros|registro]] com o símbolo
e os ponteiros esq e dir):
- operando: cria uma folha e empilha o ponteiro;
- operador: desempilha dois ponteiros (direita, depois esquerda), cria um
  nó com o operador e esses dois filhos e empilha o novo nó;
- no fim, a pilha contém a raiz da árvore.

Assim, infixa -> posfixa -> árvore usa duas pilhas e leva tempo linear.

## Onde isso é usado

- Compiladores e interpretadores: o analisador sintático transforma cada
  expressão do programa numa árvore (a árvore sintática), da qual o código
  de máquina é gerado com um percurso em pós-ordem. Máquinas virtuais como
  a do Java executam código de pilha, que é essencialmente notação
  posfixa.
- Calculadoras: as calculadoras científicas HP usam a notação polonesa
  reversa diretamente, com a tecla ENTER para empilhar números.
- Planilhas e linguagens de consulta, que precisam avaliar fórmulas
  digitadas pelo usuário.
- A linguagem PostScript, de descrição de páginas, e a linguagem Forth são
  inteiramente posfixas.

## Histórico

O lógico polonês Jan Łukasiewicz inventou a notação prefixa por volta de
1924, para escrever fórmulas de lógica sem parênteses; por isso ela é
chamada notação polonesa. Charles L. Hamblin, na Austrália, propôs em 1957
a notação posfixa (polonesa reversa) para computadores e o uso de uma
pilha para avaliá-la, na mesma época em que Friedrich L. Bauer e Klaus
Samelson, na Alemanha, usavam pilhas para traduzir fórmulas. Edsger W.
Dijkstra descreveu o algoritmo da estação de manobras em 1961, para o
primeiro compilador de ALGOL 60.

O programa converte quatro expressões infixas (com operandos de um dígito,
os operadores + - * / e parênteses) para a posfixa, calcula o valor com
uma pilha, monta a árvore de expressão com uma pilha de ponteiros e mostra
os percursos em pré-ordem, pós-ordem e in-ordem com parênteses, a altura

#include <stdio.h>
#include <stdlib.h>
#include <ctype.h>
#define MAX 100

/* precedência dos operadores: * e / antes de + e - */
int prec(char op) { return (op == '*' || op == '/') ? 2 : (op == '+' || op == '-') ? 1 : 0; }

/* infixa -> posfixa (algoritmo da estação de manobras, com pilha de operadores);
   operandos de um dígito, operadores + - * / e parênteses */
void posfixa(const char *in, char *out) {
  char pilha[MAX];
  int topo = 0, k = 0;
  for (; *in; in++) {
    char c = *in;
    if (isdigit((unsigned char)c)) out[k++] = c;           /* operando: vai direto */
    else if (c == '(') pilha[topo++] = c;
    else if (c == ')') {                                   /* desempilha até o '(' */
      while (topo > 0 && pilha[topo - 1] != '(') out[k++] = pilha[--topo];
      topo--;                                              /* descarta o '(' */
    } else if (prec(c)) {                                  /* operador */
      while (topo > 0 && prec(pilha[topo - 1]) >= prec(c)) out[k++] = pilha[--topo];
      pilha[topo++] = c;
    }                                                      /* espaços são ignorados */
  }
  while (topo > 0) out[k++] = pilha[--topo];
  out[k] = '\0';
}

int aplica(char op, int a, int b) {
  switch (op) { case '+': return a + b; case '-': return a - b;
                case '*': return a * b; default:  return a / b; }
}

/* avalia a posfixa com uma pilha de valores */
int avalia(const char *pos) {
  int pilha[MAX], topo = 0, a, b;
  for (; *pos; pos++)
    if (isdigit((unsigned char)*pos)) pilha[topo++] = *pos - '0';
    else { b = pilha[--topo]; a = pilha[--topo]; pilha[topo++] = aplica(*pos, a, b); }
  return pilha[0];
}

/* árvore de expressão: folhas são operandos, nós internos são operadores */
typedef struct no { char c; struct no *esq, *dir; } No;

No *novo(char c, No *e, No *d) {
  No *n = malloc(sizeof(No));
  if (n == NULL) { perror("malloc"); exit(1); }
  n->c = c; n->esq = e; n->dir = d;
  return n;
}

/* monta a árvore lendo a posfixa com uma pilha de ponteiros para nós */
No *arvore(const char *pos) {
  No *pilha[MAX], *e, *d;
  int topo = 0;
  for (; *pos; pos++)
    if (isdigit((unsigned char)*pos)) pilha[topo++] = novo(*pos, NULL, NULL);
    else { d = pilha[--topo]; e = pilha[--topo]; pilha[topo++] = novo(*pos, e, d); }
  return pilha[0];
}

void pre_ordem(No *r) { if (r) { printf("%c ", r->c); pre_ordem(r->esq); pre_ordem(r->dir); } }
void pos_ordem(No *r) { if (r) { pos_ordem(r->esq); pos_ordem(r->dir); printf("%c ", r->c); } }
void in_ordem(No *r) {                       /* in-ordem com parênteses em volta de cada operador */
  if (!r) return;
  if (r->esq) printf("(");
  in_ordem(r->esq); printf("%c", r->c); in_ordem(r->dir);
  if (r->esq) printf(")");
}
int altura(No *r) {                    /* em arestas: uma folha tem altura 0 */
  int he, hd;
  if (!r) return -1;
  he = altura(r->esq); hd = altura(r->dir);
  return 1 + (he > hd ? he : hd);
}
int valor(No *r) {                     /* avaliação = percurso em pós-ordem */
  if (!r->esq) return r->c - '0';
  return aplica(r->c, valor(r->esq), valor(r->dir));
}
void libera(No *r) { if (r) { libera(r->esq); libera(r->dir); free(r); } }

int main(void) {
  const char *testes[] = {"(5 + 3) * 2 - 8 / 4", "2 + 3 * 4", "(2 + 3) * 4", "9 - 4 - 3"};
  char p[MAX];
  int t;
  for (t = 0; t < 4; t++) {
    No *r;
    posfixa(testes[t], p);
    r = arvore(p);
    printf("infixa: %-22s posfixa: %-10s valor: %d\n", testes[t], p, avalia(p));
    printf("  árvore -> pré: "); pre_ordem(r);
    printf(" pós: "); pos_ordem(r);
    printf(" in: "); in_ordem(r);
    printf("\n  altura %d, valor pela árvore %d\n", altura(r), valor(r));
    libera(r);
  }
  return 0;
}
