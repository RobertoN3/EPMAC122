6. Problema: Dados dois inteiros a e b, não negativos e não ambos nulos, determinar o maior inteiro que divide os dois, o máximo divisor comum mdc(a, b)
7. Titulo: MDC e algoritmo de Euclides

## Ideia geral

O máximo divisor comum de dois inteiros a e b, escrito mdc(a, b), é o maior
inteiro que divide os dois sem deixar resto. Por exemplo, mdc(12, 18) = 6,
mdc(17, 5) = 1 e mdc(8, 0) = 8 (todo inteiro divide 0). É usado para
simplificar frações (12/18 = 2/3, dividindo por 6), calcular o mínimo
múltiplo comum e, com a versão estendida, em criptografia.

Na disciplina, o MDC é o exemplo escolhido para apresentar os INVARIANTES:
afirmações que valem a cada passo de um laço e que permitem provar, por
[[inducao|indução]], que o algoritmo está correto. Esta página é a
referência do site para invariantes.

## Uma solução ingênua

A ideia mais direta é testar os candidatos, do maior possível para baixo:

```
  mdc_ingenuo(a, b):              (a, b > 0)
      d <- min(a, b)
      enquanto a % d != 0 ou b % d != 0:
          d <- d - 1
      devolva d
```

Invariante: nenhum inteiro maior que d divide a e b ao mesmo tempo. Ele vale
no início (nenhum número maior que min(a, b) divide o menor deles) e é
mantido a cada decremento (só se descarta d depois de ver que ele não
serve). Quando o laço para, d divide os dois e nenhum maior divide: d é o
mdc. O laço termina porque d = 1 sempre serve.

Correta, mas lenta: no pior caso faz min(a, b) tentativas. Para números de
18 dígitos, seriam cerca de 10^18 divisões.

## O algoritmo de Euclides

A observação de Euclides: um número divide a e b se e somente se divide b e
a % b (o resto da divisão de a por b). Logo, para b > 0,

```
  mdc(a, b) = mdc(b, a % b)
  mdc(a, 0) = a
```

Como o resto é sempre menor que o divisor, o segundo argumento diminui a
cada passo e chega a 0. Em pseudocódigo:

```
  euclides(a, b):
      enquanto b != 0:
          r <- a % b
          a <- b
          b <- r
      devolva a
```

Por que a observação vale: a % b = a - q·b, em que q é o quociente.

- Se d divide a e b, divide a - q·b, isto é, divide a % b.
- Se d divide b e a % b, divide q·b + (a % b), isto é, divide a.

Os pares (a, b) e (b, a % b) têm exatamente os mesmos divisores comuns e,
portanto, o mesmo máximo divisor comum.

## Exemplo

mdc(1071, 462):

```
  1071 = 2 x 462 + 147
   462 = 3 x 147 +  21
   147 = 7 x  21 +   0      -> mdc = 21
```

Três divisões, contra 442 tentativas da solução ingênua (de 462 até 21).

## Invariantes: como provar que um laço está certo

Um invariante de laço é uma afirmação sobre as variáveis que vale toda vez
que o laço vai começar uma nova iteração. Para usá-lo numa prova, mostram-se
três coisas, como numa demonstração por indução no número de iterações:

1) Inicialização: o invariante vale antes da primeira iteração.
2) Manutenção: se vale no início de uma iteração, continua valendo no
   início da próxima.
3) Término: quando o laço para, o invariante, junto com a condição de
   parada, dá o resultado desejado.

No algoritmo de Euclides, sejam a0 e b0 os valores iniciais. O invariante é:

```
  mdc(a, b) = mdc(a0, b0)
```

- Inicialização: no começo, a = a0 e b = b0.
- Manutenção: cada iteração troca (a, b) por (b, a % b), que tem o mesmo
  mdc, como vimos.
- Término: o laço para com b = 0, e mdc(a, 0) = a; pelo invariante, a é
  mdc(a0, b0).

Falta provar que o laço termina: b é um inteiro não negativo que diminui
estritamente a cada iteração (a % b < b), e não existe sequência infinita
estritamente decrescente de naturais.

O mesmo roteiro prova vários algoritmos do site: a
[[busca_sequencial|busca sequencial]] (x não está em v[0..j-1]), a
[[selecao_direta|seleção direta]] (v[0..i-1] tem os i menores elementos,
em ordem), a [[insertionsort|inserção direta]], a [[bubblesort|bolha]] e a
[[busca_binaria|busca binária]].

## Eficiência

Quantas divisões o algoritmo de Euclides faz? Note que, a cada duas
iterações, o primeiro número cai pelo menos pela metade (se b <= a/2, então
a % b < b <= a/2; se b > a/2, então a % b = a - b < a/2). Logo o número de
iterações é O(log min(a, b)): proporcional ao número de DÍGITOS dos
números, e não ao valor deles.

O pior caso acontece com números de Fibonacci consecutivos: mdc(55, 34)
passa por (34, 21), (21, 13), (13, 8), (8, 5), (5, 3), (3, 2), (2, 1),
(1, 0), num total de 8 divisões, porque cada resto é o número de Fibonacci
anterior. Em 1844, Gabriel Lamé provou que o número de divisões nunca passa
de 5 vezes o número de dígitos decimais do menor número: foi uma das
primeiras análises de complexidade de um algoritmo.

## Versão recursiva e aplicações

A definição mdc(a, b) = mdc(b, a % b) é naturalmente
[[recursao|recursiva]]:

```
  mdc(a, b): se b == 0, devolva a; senão, devolva mdc(b, a % b)
```

É uma recursão de cauda: a chamada recursiva é a última coisa que a função
faz, e o compilador pode transformá-la num laço.

Aplicações:
- frações irredutíveis: dividir numerador e denominador pelo mdc;
- mínimo múltiplo comum: mmc(a, b) = a / mdc(a, b) x b (dividir antes de
  multiplicar evita estouro);
- o algoritmo de Euclides estendido, que também acha inteiros x e y com
  a·x + b·y = mdc(a, b), é usado para calcular inversos modulares na
  criptografia RSA.

## Histórico

O algoritmo aparece nos Elementos de Euclides, por volta de 300 a.C. (livro
VII, proposições 1 e 2), formulado com subtrações sucessivas de segmentos:
subtrair repetidamente o menor do maior é o mesmo que tomar o resto. Knuth
o considera o algoritmo não trivial mais antigo ainda em uso, e dedica a
ele uma longa seção do volume 2 de "The Art of Computer Programming".

INICIO_CODIGO_C
#include <stdio.h>

long passos;               /* contador de iterações */

/* testa os candidatos de min(a,b) para baixo (a, b > 0) */
int mdc_ingenuo(int a, int b) {
  int d = a < b ? a : b;
  for (;;) {               /* invariante: nenhum inteiro > d divide a e b */
    passos++;
    if (a % d == 0 && b % d == 0) return d;
    d--;
  }
}

/* algoritmo de Euclides; se mostrar != 0, imprime cada divisão */
int mdc_euclides(int a, int b, int mostrar) {
  while (b != 0) {         /* invariante: mdc(a,b) = mdc dos valores iniciais */
    int r = a % b;
    passos++;
    if (mostrar) printf("  %4d = %d x %3d + %3d\n", a, a / b, b, r);
    a = b;
    b = r;
  }
  return a;
}

int mdc_rec(int a, int b) {
  return b == 0 ? a : mdc_rec(b, a % b);   // recursão de cauda
}

void compara(int a, int b) {
  int g1, g2;
  passos = 0; g1 = mdc_ingenuo(a, b);
  printf("mdc(%d, %d): ingênuo = %d em %ld passos; ", a, b, g1, passos);
  passos = 0; g2 = mdc_euclides(a, b, 0);
  printf("Euclides = %d em %ld passos\n", g2, passos);
}

int main(void) {
  printf("Divisões de mdc(1071, 462):\n");
  printf("  resultado: %d\n\n", mdc_euclides(1071, 462, 1));
  compara(1071, 462);
  compara(55, 34);          /* números de Fibonacci: pior caso */
  compara(1000000, 999999);
  printf("\nrecursivo: mdc(1071, 462) = %d\n", mdc_rec(1071, 462));
  printf("mmc(12, 18) = %d\n", 12 / mdc_rec(12, 18) * 18);
  return 0;
}
