6. Problema: Dada uma sequência de matrizes A1, A2, ..., An, em que Ai tem p[i-1] linhas e p[i] colunas, escolher a ordem dos produtos (a parentização) que calcula A1·A2·...·An com o menor número de multiplicações de números
7. Titulo: Multiplicação de uma cadeia de matrizes

## Ideia geral

O produto de matrizes é associativo: (A·B)·C = A·(B·C). O resultado é o
mesmo, mas o TRABALHO pode ser muito diferente. Multiplicar uma matriz
p x q por uma q x r faz p·q·r multiplicações de números (cada uma das p·r
posições do resultado é uma soma de q produtos).

Exemplo com A1 (10 x 100), A2 (100 x 5) e A3 (5 x 50):

```
  (A1·A2)·A3:  10·100·5 + 10·5·50   =  5 000 +  2 500 =  7 500
  A1·(A2·A3):  100·5·50 + 10·100·50 = 25 000 + 50 000 = 75 000
```

Só mudar a ordem dos parênteses torna o cálculo dez vezes mais barato. O
problema é escolher, entre todas as parentizações, a de menor custo. Ele
foi apresentado já na primeira semana da disciplina como exemplo de
[[programacao_dinamica|programação dinâmica]], e aparece em computação
gráfica, em álgebra linear numérica e em redes neurais, onde a mesma
sequência de produtos é repetida milhões de vezes.

## Por que não testar todas

O número de parentizações de n matrizes é o número de Catalan C(n-1):
1, 1, 2, 5, 14, 42, 132, ... Ele cresce como 4^n, então testar todas é
inviável: para 20 matrizes já são mais de 1,7 bilhão de ordens diferentes.

## Subestrutura ótima

Numa parentização qualquer de Ai...Aj, o ÚLTIMO produto feito divide a
cadeia em duas partes, (Ai...Ak)·(Ak+1...Aj), para algum k entre i e j-1.
Se a parentização inteira é ótima, as duas partes também têm de estar
calculadas da melhor forma: se houvesse um jeito mais barato de calcular
Ai...Ak, bastaria usá-lo para melhorar o todo. É o princípio da
otimalidade de Bellman, e ele permite escrever uma recorrência.

Seja m[i][j] o menor custo para calcular Ai...Aj. Então:

```
  m[i][i] = 0                          (uma matriz só: nada a fazer)
  m[i][j] = min  { m[i][k] + m[k+1][j] + p[i-1]·p[k]·p[j] }
          i<=k<j
```

O termo p[i-1]·p[k]·p[j] é o custo do último produto: a parte esquerda é
uma matriz p[i-1] x p[k] e a direita, p[k] x p[j].

## Subproblemas sobrepostos

Calcular a recorrência diretamente, com uma função recursiva, repete os
mesmos subproblemas muitas e muitas vezes: o trecho A2...A3, por exemplo,
aparece dentro de todas as divisões que o deixam inteiro. Para n matrizes
a recursão ingênua faz 3^(n-1) chamadas (243 para n = 6), embora só
existam n(n+1)/2 trechos Ai...Aj diferentes (21 para n = 6).

A programação dinâmica calcula cada trecho uma única vez, guardando o
resultado na tabela m. Pode ser feita de cima para baixo, com
[[recursao|recursão]] e memoização, ou de baixo para cima, preenchendo a
tabela em ordem crescente de tamanho do trecho: primeiro todos os pares,
depois todos os trios, e assim por diante. Assim, quando m[i][j] é
calculado, os trechos menores de que ele depende já estão prontos.

## Reconstruindo a resposta

O valor m[1][n] diz o custo mínimo, mas não a ordem. Para recuperá-la,
guarda-se em s[i][j] o k que deu o mínimo. A parentização ótima de Ai...Aj
é então (parentização de Ai...As)(parentização de As+1...Aj), com
s = s[i][j], escrita recursivamente até chegar a matrizes isoladas.

## Exemplo

Seis matrizes com dimensões p = (30, 35, 15, 5, 10, 20, 25), o exemplo
clássico do livro de Cormen e colegas. A tabela m[i][j] (só a metade de
cima faz sentido):

```
          j=1     2      3      4      5      6
  i=1       0  15750   7875   9375  11875  15125
  i=2              0   2625   4375   7125  10500
  i=3                     0    750   2500   5375
  i=4                            0   1000   3500
  i=5                                   0   5000
  i=6                                          0
```

Custo mínimo: 15 125 multiplicações, com a ordem ((A1(A2A3))((A4A5)A6)).
A ordem da esquerda para a direita, (((((A1A2)A3)A4)A5)A6), custaria
40 500.

## Análise

- A tabela tem cerca de n²/2 casas, e cada uma testa até n valores de k:
  tempo O(n³).
- Memória: as tabelas m e s, O(n²).
- Comparando: a força bruta é exponencial (Catalan), a recursão ingênua
  também (3^(n-1) chamadas), e a programação dinâmica é polinomial.

Existe um algoritmo O(n log n) para este problema (Hu e Shing, 1982), mas
ele é muito mais complicado. Na prática, como n costuma ser pequeno e o
custo real está nos produtos das matrizes, o O(n³) é mais que suficiente.

## Outros problemas com a mesma forma

A mesma estrutura, em que se escolhe um ponto de divisão k num intervalo
[i, j], resolve outros problemas: a árvore binária de busca ótima (dadas
as frequências de busca de cada chave), a triangulação de polígonos de
menor custo e a análise sintática de frases por gramáticas (algoritmo
CYK). Veja também a [[eficiencia|eficiência de algoritmos]] e a
[[divisao_conquista|divisão e conquista]], que divide sem guardar
resultados.

## Histórico

O algoritmo de programação dinâmica para este problema foi publicado por
S. S. Godbole em 1973, num artigo da IEEE Transactions on Computers, e se
tornou um dos exemplos mais usados para ensinar a técnica. T. C. Hu e
M. T. Shing encontraram em 1982 o algoritmo O(n log n), baseado numa
relação entre parentizações e triangulações de polígonos.

## Sobre o código

O programa resolve o exemplo de três matrizes desta página (comparando as
duas ordens), preenche a tabela m para as seis matrizes do exemplo, mostra
o custo mínimo e a parentização ótima e confere o resultado com a recursão
ingênua, contando as suas chamadas.

#include <stdio.h>
#define MAX 10

/* dimensões: a matriz Ai tem p[i-1] linhas e p[i] colunas */
long m[MAX][MAX];   /* m[i][j]: menor custo para calcular Ai...Aj */
int  s[MAX][MAX];   /* s[i][j]: onde fica o último produto nesse ótimo */
long chamadas = 0;  /* chamadas da versão recursiva ingênua */

/* recursão direta da definição: tempo exponencial */
long custo_rec(const int p[], int i, int j) {
  long melhor = -1, c;
  int k;
  chamadas++;
  if (i == j) return 0;
  for (k = i; k < j; k++) {
    c = custo_rec(p, i, k) + custo_rec(p, k + 1, j) + (long)p[i - 1] * p[k] * p[j];
    if (melhor < 0 || c < melhor) melhor = c;
  }
  return melhor;
}

/* programação dinâmica de baixo para cima, por tamanho do trecho: O(n^3) */
void cadeia(const int p[], int n) {
  int i, j, k, tam;
  long c;
  for (i = 1; i <= n; i++) m[i][i] = 0;
  for (tam = 2; tam <= n; tam++)
    for (i = 1; i + tam - 1 <= n; i++) {
      j = i + tam - 1;
      m[i][j] = -1;
      for (k = i; k < j; k++) {                    /* último produto: (Ai..Ak)(Ak+1..Aj) */
        c = m[i][k] + m[k + 1][j] + (long)p[i - 1] * p[k] * p[j];
        if (m[i][j] < 0 || c < m[i][j]) { m[i][j] = c; s[i][j] = k; }
      }
    }
}

/* reconstrói a parentização ótima a partir de s */
void imprime(int i, int j) {
  if (i == j) { printf("A%d", i); return; }
  printf("(");
  imprime(i, s[i][j]);
  imprime(s[i][j] + 1, j);
  printf(")");
}

int main(void) {
  int p3[] = {10, 100, 5, 50};
  int p6[] = {30, 35, 15, 5, 10, 20, 25};
  int i, j;
  long ingenuo;

  cadeia(p3, 3);
  printf("A1(10x100) A2(100x5) A3(5x50)\n");
  printf("  (A1 A2) A3 custa %ld, A1 (A2 A3) custa %ld; ótimo = %ld: ",
         10L * 100 * 5 + 10L * 5 * 50, 100L * 5 * 50 + 10L * 100 * 50, m[1][3]);
  imprime(1, 3);
  printf("\n\n");

  cadeia(p6, 6);
  printf("Seis matrizes, dimensões 30 35 15 5 10 20 25. Tabela m[i][j]:\n");
  for (i = 1; i <= 6; i++) {
    for (j = 1; j <= 6; j++)
      if (j < i) printf("%7s", ""); else printf("%7ld", m[i][j]);
    printf("\n");
  }
  printf("Custo mínimo: %ld multiplicações. Ordem: ", m[1][6]);
  imprime(1, 6);
  ingenuo = custo_rec(p6, 1, 6);          /* calcula antes: a ordem dos argumentos de printf não é garantida */
  printf("\nA recursão ingênua chega ao mesmo valor (%ld) com %ld chamadas.\n", ingenuo, chamadas);
  return 0;
}
