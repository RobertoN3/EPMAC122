2. Algoritmo: Prim para árvore espalhada mínima
3. Autores: Vojtěch Jarník, Robert C. Prim, Edsger W. Dijkstra
4. Data: 1930, 1957, 1959

6. Problema: Dado um [[grafos|grafo]] não dirigido e conexo com pesos nas arestas, determinar sua [[kruskal|árvore espalhada mínima]], isto é, a [[arvores|árvore]] que liga todos os vértices com a menor soma de pesos
7. Titulo: Algoritmo de Prim

## Ideia geral

O algoritmo de Prim resolve o mesmo problema do algoritmo de
[[kruskal|Kruskal]]: encontrar a árvore espalhada mínima de um grafo
conexo com pesos, isto é, o conjunto de arestas de menor peso total que liga
todos os vértices sem formar ciclos. A página do Kruskal explica o problema
e suas aplicações em detalhe.

A diferença está na estratégia. O Kruskal mantém uma floresta de vários
pedaços que vão se fundindo. O Prim faz crescer UMA única [[arvores|árvore]], a partir
de um vértice inicial qualquer:

1) Comece com a árvore T contendo só o vértice inicial s.
2) Enquanto T não contiver todos os vértices: entre as arestas que ligam um
   vértice de T a um vértice fora de T, escolha a mais leve e acrescente-a
   (junto com o vértice novo) a T.

É um [[metodo_guloso|método guloso]]: a função critério é "a aresta mais
leve que sai da árvore", e cada escolha é definitiva.

## Implementação com o vetor custo

Procurar a aresta mais leve olhando todas as arestas a cada passo seria
caro. Em vez disso, mantém-se, para cada vértice v fora da árvore:
- custo[v]: o peso da aresta mais leve que liga v a algum vértice da árvore
  (infinito se não há nenhuma);
- pai[v]: a ponta dessa aresta que está na árvore.

A cada passo, o vértice que entra é o de menor custo, e só os custos dos
vizinhos dele precisam ser atualizados:

```
  custo[v] = infinito para todo v; custo[s] = 0; pai[s] = -1
  repita n vezes:
      u <- vértice fora da árvore com menor custo
      coloque u na árvore (com a aresta pai[u]-u, se u != s)
      para cada vizinho v de u fora da árvore:
          se peso(u, v) < custo[v]:
              custo[v] = peso(u, v); pai[v] = u
```

## Exemplo

O mesmo grafo da página do Kruskal: vértices 0 a 5 e arestas (u-v: peso)
0-1: 4, 0-2: 3, 1-2: 1, 1-3: 2, 2-3: 4, 3-4: 2, 4-5: 6, 3-5: 7. Começando
em 0, com custo[v](pai) dos vértices ainda fora da árvore:

```
  entra   aresta    custos depois da atualização
  0       -         1:4(0)  2:3(0)  3:inf  4:inf  5:inf
  2       0-2 (3)   1:1(2)  3:4(2)  4:inf  5:inf
  1       2-1 (1)   3:2(1)  4:inf  5:inf
  3       1-3 (2)   4:2(3)  5:7(3)
  4       3-4 (2)   5:6(4)
  5       4-5 (6)   -
```

Peso total: 3 + 1 + 2 + 2 + 6 = 14, o mesmo encontrado pelo Kruskal. As
arestas escolhidas também são as mesmas, só que em outra ordem. Quando os
pesos são todos distintos, a árvore espalhada mínima é única.

## Por que o algoritmo está correto

Invariante: a árvore T construída até o momento está contida em alguma
árvore espalhada mínima.

Considere o corte que separa os vértices de T de todos os outros. A aresta
escolhida pelo Prim é, por definição, a mais leve que cruza esse corte.
Pela propriedade do corte (provada na página do [[kruskal|Kruskal]]), ela
pertence a alguma árvore espalhada mínima que contém T. Logo o invariante
continua valendo. No fim, T tem todos os vértices e é uma árvore espalhada
mínima.

Os dois algoritmos são casos particulares da mesma propriedade: o Prim usa
sempre o corte "árvore x resto"; o Kruskal, o corte "componente de u x
resto".

## Complexidade

Depende de como se encontra o vértice de menor custo:
- Varrendo o vetor custo: O(n) por passo e O(n²) no total, com matriz de
  adjacência. É a melhor escolha para grafos densos (m da ordem de n²), e é
  a versão do programa de exemplo.
- Com uma [[heapsort|fila de prioridade em heap]] e listas de adjacência:
  O(m log n), melhor para grafos esparsos.
- Com heap de Fibonacci: O(m + n log n).

O Kruskal custa O(m log n), dominado pela ordenação das arestas. Em grafos
esparsos, os dois são equivalentes; em grafos densos, o Prim com matriz
ganha. Veja [[eficiencia|eficiência de algoritmos]].

## Prim x Dijkstra

O algoritmo de [[dijkstra|Dijkstra]] tem exatamente a mesma estrutura:
uma árvore que cresce a partir de s, sempre pelo vértice de menor valor, com
atualização dos vizinhos. A única diferença é o valor:
- Prim: custo[v] = peso da aresta mais leve de v até a árvore;
- Dijkstra: dist[v] = comprimento do caminho mais curto de s até v, ou
  seja, dist[u] + peso(u, v).
Por isso o Prim encontra a rede mais barata que liga todos os vértices, e o
Dijkstra, os caminhos mais curtos a partir de s. São problemas diferentes:
a árvore espalhada mínima não dá, em geral, os caminhos mínimos.

## Histórico

O algoritmo foi descoberto pelo matemático tcheco Vojtěch Jarník em 1930,
numa carta e num artigo em tcheco que responderam ao trabalho de Otakar
Borůvka (1926) sobre redes elétricas. Ficou pouco conhecido até ser
redescoberto por Robert C. Prim, nos Laboratórios Bell, em 1957, para
projetar redes de telecomunicações, e de novo por Edsger W. Dijkstra, em
1959, no mesmo artigo em que publicou seu algoritmo de caminhos mínimos. Por
isso também é chamado de algoritmo de Jarník, de Prim-Jarník ou de
Prim-Dijkstra.

#include <stdio.h>
#include <limits.h>
#define MAXV 10
#define INF INT_MAX

int peso[MAXV][MAXV];   /* 0 indica que não há aresta */

void aresta(int u, int v, int p) {
  peso[u][v] = peso[v][u] = p;          /* grafo não dirigido */
}

/* Prim a partir de s, versão O(n²); devolve o peso total */
int prim(int nv, int s) {
  int custo[MAXV], pai[MAXV], na_arvore[MAXV];
  int i, u, v, total = 0;

  for (v = 0; v < nv; v++) {
    custo[v] = INF;
    pai[v] = -1;
    na_arvore[v] = 0;
  }
  custo[s] = 0;

  for (i = 0; i < nv; i++) {
    u = -1;                             /* vértice fora da árvore de menor custo */
    for (v = 0; v < nv; v++)
      if (!na_arvore[v] && (u == -1 || custo[v] < custo[u]))
        u = v;
    na_arvore[u] = 1;
    if (pai[u] != -1) {
      printf("aresta %d-%d (peso %d)\n", pai[u], u, peso[pai[u]][u]);
      total += peso[pai[u]][u];
    }
    for (v = 0; v < nv; v++)            /* atualiza os vizinhos de u */
      if (peso[u][v] && !na_arvore[v] && peso[u][v] < custo[v]) {
        custo[v] = peso[u][v];
        pai[v] = u;
      }
  }
  return total;
}

int main(void) {
  aresta(0, 1, 4); aresta(0, 2, 3); aresta(1, 2, 1); aresta(1, 3, 2);
  aresta(2, 3, 4); aresta(3, 4, 2); aresta(4, 5, 6); aresta(3, 5, 7);
  printf("Peso total: %d\n", prim(6, 0));
  return 0;
}
