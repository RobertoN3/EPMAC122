7. Titulo: Ponteiros e endereços

## Ideia geral

A memória do computador pode ser vista como um enorme vetor de bytes. Cada
byte tem um número de ordem, o seu endereço. Toda variável de um programa
ocupa alguns bytes consecutivos (em geral, um char ocupa 1 byte, um int 4 e
um double 8), e o endereço da variável é o endereço do primeiro desses
bytes.

Um ponteiro (ou apontador) é uma variável cujo valor é um endereço. Dizemos
que o ponteiro "aponta" para a variável que está naquele endereço. É como a
diferença entre uma casa e o seu endereço escrito em um papel: com o papel
na mão, podemos ir até a casa e mudar o que há dentro dela.

Ponteiros estão no coração da linguagem C. Sem eles não seria possível:
- uma função alterar variáveis de quem a chamou;
- passar vetores grandes para funções sem copiá-los;
- criar estruturas cujo tamanho só se conhece durante a execução;
- ligar dados entre si, formando [[listas_encadeadas|listas encadeadas]], [[arvores|árvores]] e [[grafos]].

## Operadores & e *

- &x é o endereço da variável x ("endereço de x").
- *p é o conteúdo da posição para onde p aponta ("o que está apontado por
  p"). Essa operação chama-se desreferência (ou indireção).

Declaração: int *p; declara p como um ponteiro para int. O tipo apontado
importa: diz quantos bytes ler e como interpretá-los, e é usado na
aritmética de ponteiros.

Exemplo:

```
  int x = 1;
  int *p;
  p = &x;      // p aponta para x
  *p = 10;     // o mesmo que x = 10
  printf("%d", x);    // imprime 10
```

Depois de p = &x, a expressão *p é um outro nome (um apelido) para x.

Atenção para os dois usos do asterisco: na declaração (int *p) ele indica que
p é um ponteiro; em uma expressão (*p = 10) ele faz a desreferência.

## O ponteiro NULL e os erros comuns

NULL é um valor especial, definido em stdio.h e stdlib.h, que não aponta
para nenhuma variável válida. É usado para indicar "nenhum": o fim de uma
lista encadeada, uma subárvore vazia, uma busca sem sucesso, uma falha do
malloc.

Erros clássicos com ponteiros:
- desreferenciar NULL: o programa costuma ser abortado (segmentation fault);
- usar um ponteiro não inicializado: ele contém lixo e aponta para um lugar
  qualquer da memória;
- ponteiro pendente (dangling): continuar usando um ponteiro depois de
  liberar com free a memória para onde ele aponta, ou devolver o endereço de
  uma variável local de uma função que já terminou;
- vazamento de memória: perder o último ponteiro para um bloco alocado sem
  liberá-lo.

## Passagem de parâmetros por referência

Em C, os argumentos são sempre passados por valor: a função recebe CÓPIAS
dos valores. Por isso esta função não funciona:

```
  void trocaErrada(int a, int b) { int aux = a; a = b; b = aux; }
```

Ela troca as cópias, e as variáveis de quem chamou ficam intactas. A solução
é passar os ENDEREÇOS das variáveis:

```
  void troca(int *a, int *b) { int aux = *a; *a = *b; *b = aux; }
  ...
  troca(&x, &y);
```

A função recebe cópias dos endereços, mas, desreferenciando-os, chega às
variáveis originais. É por isso que scanf("%d", &n) precisa do &: scanf
precisa saber ONDE guardar o número lido. Passar endereços também é a
forma de uma função "devolver" mais de um resultado.

## Ponteiros e vetores

Em C, ponteiros e vetores estão intimamente ligados:
- o nome de um vetor, em quase todas as expressões, é convertido em um
  ponteiro para seu primeiro elemento: v equivale a &v[0];
- somar um inteiro i a um ponteiro p o avança i ELEMENTOS (não i bytes): se p
  aponta para v[0], então p + i aponta para v[i]. É a aritmética de
  ponteiros, e é por isso que o tipo apontado importa;
- v[i] é, por definição, *(v + i).

Consequências:
- uma função declarada como f(int v[], int n) recebe, na verdade, um
  ponteiro (int *v). O vetor não é copiado, e a função pode alterar o vetor
  original, como fazem todas as funções de ordenação;
- dentro da função não há como saber o tamanho do vetor; por isso ele é
  passado separadamente (n). Cuidado com sizeof: aplicado ao próprio vetor
  (int v[10]; sizeof v), dá o tamanho do vetor inteiro, pois aí o nome NÃO é
  convertido em ponteiro; aplicado a um parâmetro declarado como int v[],
  dá o tamanho de um ponteiro;
- pode-se formar o ponteiro para a posição logo DEPOIS do último elemento
  (v + n) e usá-lo como limite de um percurso, como em
  for (p = v; p != v + n; p++), mas nunca desreferenciá-lo. Comparar ou
  subtrair ponteiros só faz sentido entre posições do mesmo vetor;
- cadeias de caracteres são vetores de char terminados por '\0', e
  manipulá-las é, em grande parte, manipular ponteiros.

## Alocação dinâmica de memória

Variáveis comuns têm tamanho fixado ao escrever o programa. Quando o tamanho
só é conhecido durante a execução (quantos números o usuário vai digitar?),
usa-se alocação dinâmica, com funções de stdlib.h:

- malloc(n): reserva um bloco de n bytes e devolve seu endereço, ou NULL se
  não houver memória. Usa-se com sizeof: v = malloc(n * sizeof(int));
- calloc(n, tam): como malloc, mas zera o bloco;
- realloc(p, n): muda o tamanho de um bloco (pode movê-lo de lugar);
- free(p): devolve o bloco ao sistema. Todo bloco alocado deve ser liberado
  exatamente uma vez.

Os blocos alocados dinamicamente ficam em uma área chamada heap (que não tem
relação com a estrutura de dados heap) e existem até serem liberados,
independentemente da função que os criou. É assim que são criadas as células
de listas encadeadas e os nós de árvores.

## Ponteiros para registros

Se p aponta para uma struct, o campo nota dessa struct é (*p).nota. Como
isso é muito usado, C oferece a abreviação p->nota. Os parênteses em
(*p).nota são necessários porque o ponto tem precedência maior que o
asterisco.

## Outros usos

- ponteiros para ponteiros (int **pp), usados, por exemplo, em matrizes
  alocadas dinamicamente e para uma função alterar um ponteiro de quem a
  chamou;
- ponteiros para funções, como o parâmetro de comparação da função qsort,
  que permite ordenar qualquer tipo de dado;
- o ponteiro genérico void *, devolvido por malloc, que pode ser convertido
  para qualquer outro tipo de ponteiro.

## Histórico

O uso de endereços indiretos é tão antigo quanto os computadores de programa
armazenado. Harold Lawson é creditado por introduzir, em 1964, a variável
ponteiro em uma linguagem de alto nível (PL/I), e recebeu por isso o prêmio
IEEE Computer Pioneer em 2000. A linguagem C, criada por Dennis Ritchie no
Bell Labs por volta de 1972 para escrever o sistema Unix, herdou de BCPL e B
a ideia de que vetores e ponteiros são intimamente ligados, e tornou os
ponteiros uma ferramenta central da programação de sistemas.

INICIO_CODIGO_C
#include <stdio.h>
#include <stdlib.h>

/* passagem por referência: recebe os endereços */
void troca(int *a, int *b) {
  int aux = *a;
  *a = *b;
  *b = aux;
}

int main(void) {
  int x = 1, y = 2, n = 5, i;
  int *p = &x;          /* p guarda o endereço de x */
  int *v;

  *p = 10;              // altera x através de p
  printf("x = %d, endereco de x = %p\n", x, (void *)p);

  troca(&x, &y);
  printf("depois da troca: x = %d, y = %d\n", x, y);

  v = malloc(n * sizeof(int));   /* vetor com tamanho dado na execução */
  if (v == NULL) return 1;
  for (i = 0; i < n; i++)
    *(v + i) = i * i;            // o mesmo que v[i] = i * i
  for (i = 0; i < n; i++) printf("%d ", v[i]);
  printf("\n");
  free(v);
  return 0;
}
