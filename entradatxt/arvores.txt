## Ideia geral

Árvores são as estruturas não lineares mais importantes da computação. Elas
representam hierarquias: a organização de pastas e arquivos em um disco, o
organograma de uma empresa, a árvore genealógica de uma família, os
capítulos, seções e subseções de um livro, a estrutura de uma página HTML
(DOM), a estrutura de uma expressão aritmética.

## Árvores como grafos

Em teoria dos [[grafos]], uma árvore é um grafo conexo e sem ciclos. Para um
grafo T com n vértices, as afirmações abaixo são equivalentes (qualquer uma
pode servir de definição):
- T é conexo e não tem ciclos;
- T é conexo e tem exatamente n-1 arestas;
- T não tem ciclos e tem exatamente n-1 arestas;
- entre dois vértices quaisquer de T existe um único caminho;
- T é conexo, mas deixa de ser se qualquer aresta for removida
  (é "minimamente conexo");
- T não tem ciclos, mas qualquer aresta nova cria um ciclo.

Essas propriedades explicam o papel das árvores em grafos: uma árvore é a
forma mais econômica de manter todos os vértices ligados. Daí o problema da
árvore espalhada mínima ([[kruskal|algoritmo de Kruskal]]).

## Árvores enraizadas: vocabulário

Em estruturas de dados escolhe-se um vértice especial, a raiz, e
"pendura-se" a árvore a partir dela. Termos usados:
- pai e filhos: cada nó, exceto a raiz, tem exatamente um pai; os nós
  diretamente abaixo de um nó são seus filhos;
- irmãos: nós com o mesmo pai;
- ancestrais e descendentes: os nós no caminho até a raiz e os nós abaixo;
- folha (nó externo): nó sem filhos; nó interno: nó com pelo menos um filho;
- profundidade (nível) de um nó: número de arestas da raiz até ele; a raiz
  tem profundidade 0;
- altura da árvore: maior profundidade de uma folha;
- subárvore de x: x junto com todos os seus descendentes.

Uma árvore é uma estrutura [[recursao|RECURSIVA]]: ou é vazia, ou é uma raiz ligada a
uma sequência de subárvores, que também são árvores. Por isso quase todos os
algoritmos sobre árvores são recursivos e podem ser provados corretos por
indução na altura.

## Árvores binárias

Em uma árvore binária cada nó tem no máximo dois filhos, chamados esquerdo
e direito (a distinção importa: um nó só com filho esquerdo é diferente de
um nó só com filho direito). Em C, cada nó é um [[registros|registro]] (struct) com a
informação e dois [[ponteiros]], esq e dir; o valor NULL representa a subárvore
vazia.

Fatos importantes:
- o nível k tem no máximo 2^k nós;
- uma árvore binária de altura h tem no máximo 2^(h+1) - 1 nós;
- portanto, uma árvore binária com n nós tem altura pelo menos
  log2(n+1) - 1, ou seja, no mínimo da ordem de log n. Essa altura mínima é
  atingida pelas árvores "cheias" ou "quase completas";
- no outro extremo, a altura pode chegar a n-1 (árvore degenerada, que
  parece uma lista).

## Percursos (varreduras)

Percorrer uma árvore é visitar todos os seus nós. Para árvores binárias há
três percursos recursivos clássicos, que diferem apenas no momento em que a
raiz é visitada:
- pré-ordem: raiz, subárvore esquerda, subárvore direita;
- in-ordem (ordem simétrica): esquerda, raiz, direita;
- pós-ordem: esquerda, direita, raiz.
Todos custam O(n). Há ainda o percurso em largura (por níveis), que visita
a raiz, depois os nós de profundidade 1, depois os de profundidade 2, e usa
uma [[filas|FILA]], exatamente como a [[bfs|busca em largura]] em grafos.

Exemplo: na árvore da expressão (2 + 3) * 4, com * na raiz, + à esquerda e
4 à direita, os percursos dão:
- pré-ordem: * + 2 3 4   (notação prefixa ou polonesa)
- in-ordem:  2 + 3 * 4   (notação infixa, sem os parênteses)
- pós-ordem: 2 3 + 4 *   (notação posfixa, avaliada com uma [[pilhas|pilha]])
Calcular o valor da expressão é um percurso em pós-ordem: primeiro os
valores das subárvores, depois o operador da raiz.

## Árvore binária de busca (ABB)

A aplicação mais importante das árvores binárias na disciplina é a
[[abb|árvore binária de busca]]: cada nó guarda uma chave, as chaves menores
ficam na subárvore esquerda e as maiores na direita. Assim, buscar, inserir
e remover custam um tempo proporcional à altura da árvore, e o percurso
in-ordem lista as chaves em ordem crescente. Ela tem página própria.

## Árvores balanceadas

Para garantir altura O(log n) no pior caso, as árvores balanceadas
reorganizam a estrutura (por meio de "rotações") durante as inserções e
remoções:
- árvores AVL (Adelson-Velsky e Landis, 1962): em cada nó, as alturas das
  duas subárvores diferem de no máximo 1;
- árvores rubro-negras (Guibas e Sedgewick, 1978, a partir de Bayer, 1972):
  usadas, por exemplo, no std::map de C++ e no TreeMap de Java;
- árvores B (Bayer e McCreight, 1970): nós com muitos filhos, usadas em
  bancos de dados e sistemas de arquivos, onde cada acesso ao disco é caro.

## Outras árvores na disciplina

- Heap: árvore binária quase completa, guardada em um vetor, em que cada pai
  é maior ou igual aos filhos. Base do Heap Sort e das [[heapsort|filas de prioridade]].
- Árvore espalhada mínima de um grafo (Kruskal, [[prim|Prim]]).
- Árvore de caminhos mínimos (Dijkstra) e árvore de busca em largura.
- Árvore de recursão (análise de [[mergesort|Merge Sort]]) e árvore de busca do
  [[tentativa_erro|backtracking]].
- Trie (árvore digital), para dicionários de palavras, e árvore de Huffman,
  para compressão.

## Histórico

O termo "árvore" foi usado pelo matemático Arthur Cayley em 1857, ao estudar
isômeros químicos; ele também provou (1889) que há n^(n-2) árvores
diferentes com n vértices rotulados. A árvore binária de busca foi
inventada independentemente por vários grupos por volta de 1960 (Windley;
Booth e Colin; Hibbard), e Knuth dedica a ela boa parte do volume 3 de
"The Art of Computer Programming".

## Sobre o código

O programa de exemplo monta, com registros ligados por ponteiros, a árvore
da expressão (2 + 3) * 4 e a percorre recursivamente em pré-ordem, in-ordem
e pós-ordem. Em seguida calcula, também por recursão, a altura da árvore, o
número de nós e o valor da expressão (um percurso em pós-ordem), e libera a
memória.

INICIO_CODIGO_C
#include <stdio.h>
#include <stdlib.h>

/* nó de uma árvore de expressão: operador (+, -, *) ou número */
typedef struct no {
  char op;                      /* ' ' quando o nó é um número */
  int valor;
  struct no *esq, *dir;
} No;

No *cria(char op, int valor, No *esq, No *dir) {
  No *novo = malloc(sizeof(No));
  if (novo == NULL) exit(1);
  novo->op = op;
  novo->valor = valor;
  novo->esq = esq;
  novo->dir = dir;
  return novo;
}

No *numero(int x) { return cria(' ', x, NULL, NULL); }

void visita(No *r) {
  if (r->op == ' ') printf("%d ", r->valor);
  else printf("%c ", r->op);
}

void preordem(No *r) {          /* raiz, esquerda, direita */
  if (r == NULL) return;
  visita(r); preordem(r->esq); preordem(r->dir);
}

void inordem(No *r) {           /* esquerda, raiz, direita */
  if (r == NULL) return;
  inordem(r->esq); visita(r); inordem(r->dir);
}

void posordem(No *r) {          /* esquerda, direita, raiz */
  if (r == NULL) return;
  posordem(r->esq); posordem(r->dir); visita(r);
}

/* altura: -1 para a árvore vazia, 0 para uma folha */
int altura(No *r) {
  int he, hd;
  if (r == NULL) return -1;
  he = altura(r->esq);
  hd = altura(r->dir);
  return 1 + (he > hd ? he : hd);
}

int conta(No *r) {
  if (r == NULL) return 0;
  return 1 + conta(r->esq) + conta(r->dir);
}

/* valor da expressão: percurso em pós-ordem */
int avalia(No *r) {
  int a, b;
  if (r->op == ' ') return r->valor;
  a = avalia(r->esq);
  b = avalia(r->dir);
  switch (r->op) {
    case '+': return a + b;
    case '-': return a - b;
    default:  return a * b;
  }
}

void libera(No *r) {            // pós-ordem: filhos antes do pai
  if (r == NULL) return;
  libera(r->esq);
  libera(r->dir);
  free(r);
}

int main(void) {
  /* (2 + 3) * 4 */
  No *raiz = cria('*', 0, cria('+', 0, numero(2), numero(3)), numero(4));
  printf("pre-ordem: "); preordem(raiz); printf("\n");
  printf("in-ordem:  "); inordem(raiz);  printf("\n");
  printf("pos-ordem: "); posordem(raiz); printf("\n");
  printf("altura %d, %d nos, valor %d\n", altura(raiz), conta(raiz), avalia(raiz));
  libera(raiz);
  return 0;
}
