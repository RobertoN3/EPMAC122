Problema
Dado um vetor de elementos comparáveis, reorganizá-lo em ordem crescente

Ideia geral

A inserção direta (insertion sort) é o método que a maioria das pessoas usa, sem perceber, para ordenar as cartas de um jogo de baralho na mão. Pegamos as cartas uma a uma; a cada nova carta, procuramos, entre as que já estão ordenadas na mão, o lugar certo para ela, e a encaixamos ali.

No vetor v[0..n-1], a ideia é manter o início do vetor ordenado e fazê-lo crescer de um elemento por vez:

  • no início, v[0..0] (um único elemento) está trivialmente ordenado;
  • no passo i, o trecho v[0..i-1] já está ordenado; o elemento x = v[i] é inserido no lugar correto dentro desse trecho, que passa a ser v[0..i];
  • depois do passo i = n-1, o vetor inteiro está ordenado.

Para inserir x, percorre-se a parte ordenada da direita para a esquerda, deslocando uma posição para a direita cada elemento MAIOR que x, até encontrar um elemento menor ou igual a x (ou chegar ao início do vetor). O espaço aberto é onde x é colocado.

O algoritmo

  para i de 1 até n-1:
      x <- v[i]
      j <- i - 1
      enquanto j >= 0 e v[j] > x:
          v[j+1] <- v[j]       (desloca para a direita)
          j <- j - 1
      v[j+1] <- x

Repare que não se fazem trocas, só deslocamentos: x é guardado em uma variável e copiado uma única vez, no final. Isso torna a inserção mais rápida que a bolha, que faz trocas (três atribuições cada).

Exemplo

v = (12, 11, 13, 5, 6)

  i = 1, x = 11: 12 > 11 desloca          -> (11, 12, 13, 5, 6)
  i = 2, x = 13: 12 < 13, fica no lugar   -> (11, 12, 13, 5, 6)
  i = 3, x = 5:  desloca 13, 12 e 11      -> (5, 11, 12, 13, 6)
  i = 4, x = 6:  desloca 13, 12 e 11      -> (5, 6, 11, 12, 13)

Técnica: método incremental

A inserção direta é o exemplo típico do método incremental: resolve-se o problema para os i primeiros elementos e, a partir dessa solução, obtém-se a solução para os i+1 primeiros. Em termos recursivos: para ordenar v[0..i], ordena-se v[0..i-1] e depois insere-se v[i]. É uma forma de "diminuir e conquistar", em que o problema diminui uma unidade por vez (em contraste com a divisão e conquista, que o divide ao meio).

Correção: o invariante

No início de cada iteração do laço externo (para cada i):

  v[0..i-1] está em ordem crescente e contém exatamente os elementos que
  estavam originalmente em v[0..i-1].
  • Vale para i = 1 (um elemento só).
  • O laço interno desloca para a direita os elementos maiores que x e coloca x logo depois do primeiro elemento menor ou igual a ele; logo v[0..i] fica ordenado, com os mesmos elementos de antes mais x.
  • Ao final, i = n e o vetor inteiro está ordenado.

Note a diferença para a seleção direta: lá, a parte ordenada já contém os MENORES elementos do vetor, em suas posições definitivas; aqui, contém apenas os PRIMEIROS elementos, ordenados entre si, que ainda poderão ser deslocados.

Análise

O número de deslocamentos no passo i é o número de elementos de v[0..i-1] maiores que v[i]. Somando para todo i, o total de deslocamentos é exatamente o número de inversões do vetor (pares i < j com v[i] > v[j]). Portanto:

  • Melhor caso (vetor já ordenado): nenhum deslocamento e n-1 comparações: O(n).
  • Pior caso (ordem decrescente): n(n-1)/2 inversões, O(n²) comparações e deslocamentos.
  • Caso médio: n(n-1)/4 inversões em média, ou seja, cerca de n²/4 comparações e deslocamentos: O(n²), mas com a metade do trabalho do pior caso.
  • De modo geral, o custo é O(n + I), em que I é o número de inversões. Por isso a inserção é excelente para vetores "quase ordenados", com poucos elementos fora do lugar.

Memória extra: O(1). Estabilidade: o laço interno só desloca elementos ESTRITAMENTE maiores que x (condição v[j] > x); um elemento igual a x faz o laço parar, e x fica depois dele. A ordem relativa dos iguais é mantida: o método é estável. (Trocar > por >= tornaria o algoritmo instável.)

Outra vantagem: a inserção é um algoritmo online, isto é, pode ordenar os dados à medida que eles chegam, sem precisar conhecer o vetor inteiro.

Variações

  • Inserção binária: como v[0..i-1] está ordenado, a posição de x pode ser encontrada com busca binária, em O(log i) comparações. O número de deslocamentos não muda, então o algoritmo continua O(n²), mas é útil quando comparar é muito mais caro que mover (por exemplo, comparar cadeias longas).
  • Sentinela: colocando em v[0] um valor menor que todos (ou movendo o menor elemento para lá antes de começar), o teste j >= 0 do laço interno pode ser eliminado.
  • Shell sort (Donald Shell, 1959): faz várias inserções diretas sobre elementos separados por uma distância h (h-ordenação), com valores de h decrescentes até 1. Assim, elementos distantes de sua posição andam muitas casas de uma vez, e a inserção final encontra um vetor quase ordenado. Com boas sequências de distâncias, fica muito mais rápido que O(n²) na prática.
  • Em listas encadeadas a inserção não precisa deslocar nada: basta mudar ponteiros.

Na prática

Entre os métodos elementares, a inserção direta é a mais rápida na prática, e é imbatível para vetores pequenos (até algumas dezenas de elementos), porque seu laço é muito simples. Por isso as implementações profissionais de Merge Sort e Quick Sort, ao chegarem a trechos pequenos na recursão, trocam para a inserção direta. O Timsort, usado em Python e Java, aplica inserção binária para formar os pequenos trechos ordenados que depois intercala, e o Introsort, do C++, termina com inserção.

Histórico

Segundo Knuth, a inserção direta foi mencionada por John Mauchly em 1946, nas Moore School Lectures, a primeira série de aulas sobre computação eletrônica, junto com a ideia da inserção binária. O método é, claro, muito mais antigo como prática manual de quem ordena fichas ou cartas. O Shell sort, publicado em 1959, foi um dos primeiros algoritmos a "quebrar a barreira" quadrática na prática.
